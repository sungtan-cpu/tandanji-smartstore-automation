한국시간(Asia/Seoul) 매주 월요일·목요일 오전 08:05에 이 채팅의 네이버 스마트스토어 정기 작업을 실제 수행한다. 작업 폴더는 이 저장소를 내려받은 폴더이며 WORKFLOW.md의 최종 규칙과 이 프롬프트가 과거 규칙보다 우선한다. sources는 읽기 전용이다.

Chrome의 네이버 스마트스토어 판매자센터에서 네이버 아이디 로그인(tandanji_box)을 사용한다. 유지된 로그인 세션을 재사용한다. 로그인 창에 계정과 비밀번호가 자동 입력되어 있으면 로그인 버튼을 직접 클릭한다. 비밀번호를 읽어내거나 로그에 저장하지 않는다. 빈 비밀번호, 추가 인증, CAPTCHA 또는 실패가 확인될 때만 중단하고 필요한 사용자 조치를 알린다. 저장된 인증정보만으로 로그인이 가능한데 사용자에게 다시 로그인하라고 요청하지 않는다.

실행일 당일을 제외한 가장 가까운 월·목 배송일 네 개를 대한민국 공휴일·대체공휴일·임시공휴일을 최신 공식 자료로 확인해 제외하고 날짜순으로 선정한다. 그 네 날짜에 고단백도시락과 웜프 샐러드 각각 하나씩, 총 8개가 판매중·전시중이 되도록 누락만 보완한다. 단순히 네 번째 날짜만 만들거나 중간 날짜를 건너뛰지 않는다. 먼저 전체 판매상태의 상품번호·이름·상태·기간을 모두 조회해 같은 배송일/종류 중복을 막고 이미 만들어진 미래 상품은 유지한다. 부족한 종류는 오늘보다 과거 배송일인 기존 판매중지 또는 판매종료 상품 중 가장 최근 상품을 종류별로 재사용한다. 신규 등록/복사는 하지 않는다. 판매중 상품의 이름·기간은 바꾸지 않는다. 월 회차는 해당 배송월의 공휴일을 제외한 월·목 순서로 월초에 1부터 시작한다. 상품명은 MM월DD일(요일) [고단백도시락 또는 웜프 샐러드] 탄단지박스 M월 N회차. 판매 시작은 사용자 승인한 실제 수정 시간이 속한 정각, 판매 종료는 배송일의 달력상 3일 전 23:59. 가격·옵션·재고·이미지·상세·배송비 등은 변경하지 않는다. 이름/기간 저장 뒤 해당 상품만 판매중·전시중으로 처리한다. 일괄 처리 전 선택된 상품번호가 정확히 대상과 일치하는지 반드시 확인한다. 저장 후 상품을 다시 열어 이름/기간을 검증하고 판매중 목록에서 8개 모두 전시중인지 확인한다. 한 종류만 완료된 경우 재실행에서 나머지만 처리한다.

스토어관리 > 카테고리&메뉴 관리 > 홈 > 하단 자유상품의 고단백도시락/웜프 샐러드 구성에서 상품 썸네일을 배송일 오름차순으로 이동하고 적용한다. 종료 상품을 삭제하거나 다른 구성요소 설정을 바꾸지 않는다. 새로고침해 실제 홈에서 두 종류 모두 동일한 네 배송일 순서인지 확인한다.

배너 원본 폴더는 local-settings.json의 bannerDirectory에 지정된 폴더 이다. 폴더의 웹배너(PC)와 모바일배너 이미지를 실제로 열어 월·날짜·요일·회차·마감 표시를 확인한다. 파일명만으로 선택하지 않는다. 실제 판매 종료 시각을 지난 회차가 몇 개인지 기준으로 ‘전체오픈’, ‘1회차마감’ 등 현재 상황에 맞는 PC/모바일 짝을 선택한다. 날짜가 실제 공휴일 제외 배송 일정과 다르거나 대응 이미지가 없거나 여러 후보가 모호하면 임의 업로드/수정하지 않고 불일치와 필요한 파일을 알린다. 올바른 파일이 있으면 현재 배너와 비교해 필요한 PC·모바일 배너만 업로드·적용하고 다시 열어 실제 표시를 검증한다. 이름에 사용완료가 있어도 현재 적용된 이미지와 대응하는지 판단할 수 있도록 원본 날짜/단계 이름을 유지한다. 적용이 검증된 파일만 같은 폴더에서 확장자를 보존해 ‘원래이름_사용완료.png’ 형태로 이름을 변경한다. 현재 이미 적용된 파일도 일치가 검증되면 표시할 수 있다. 중복 접미사를 붙이지 않고 대상 이름이 이미 있으면 덮어쓰지 않는다. 사용하지 않은 미래 단계 파일, 실패한 업로드 파일 또는 단지 미리 본 파일은 이름을 바꾸지 않는다. 파일 변경 권한이 막히면 그 파일/폴더 작업만 필요한 권한으로 요청하고 우회하지 않는다.

outputs에 실행 날짜·시각, 상품번호, 변경 전후 이름·판매기간·상태, 전체 8개 검증, 정렬 전후, 공휴일 근거, 배너 원본/변경 파일명·적용 검증과 화면 캡처를 기록한다. 부분 성공을 전체 성공으로 보고하지 않는다. 불필요하게 같은 상품/배너를 다시 저장하지 않는다. 구글 챗 웹훅은 아직 연결되지 않았으므로 임의로 채팅방에 메시지를 전송하지 않는다.

이미지 경로는 local-settings.json을 먼저 읽어 결정한다. bannerDirectory와 menuImage를 현재 컴퓨터에서 확인하고 사용한다. 경로가 없거나 잘못됐으면 그 부분만 사용자에게 확인한다. 모든 상대 경로는 저장소 루트 기준이다. 재사용 상품에도 현재 배송월에 맞는 식단표 공지가 연결되어 있는지 확인하고, 11월에는 사용자 지정 menuImage와 대응하는 '탄단지박스 11월 식단표' 공지를 연결한다. 다른 월에는 해당 월의 확인된 파일이 필요하다. 과거 경로와 과거 상품 상태를 현재 상태로 간주하지 않는다. 중복 방지는 매번 전체 판매상태의 실시간 조회를 기준으로 한다.
