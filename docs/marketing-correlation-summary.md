# 탄단지박스 매출·광고·방문 상관관계

2026년 1월 1일~11월 8일의 고도몰 유효 주문과 Meta 광고비를 비교했다. 주문번호 중복을 제거한 뒤 집계한 주문은 13,139건, 주문 목록 표시금액은 18.68억 원, Meta 광고비는 1.34억 원이다. 방문수 비교는 GA4 기록을 확보한 6월 24일~11월 8일의 138일을 사용했다.

| 항목 | 결과 |
|---|---|
| Meta 광고비와 주문 | 일별 상관계수 0.45. 월~일이 모두 있는 44주 기준 0.73. |
| GA4 방문과 주문 | 일별 상관계수 0.51, 완료 주간 0.29. GA4에 구매와 수익이 0으로 표시되어 주문 성과는 고도몰 기준으로 비교했다. |
| 연휴 | 월·요일·광고비·먼딜 등을 보정한 모형에서 주문이 약 34% 낮았다. |
| 먼딜 | 10회 평균 직전 7일 31.7건/일, 시작일부터 10일간 60.9건/일, 직후 7일 34.3건/일. 구매 시점 이동과 순증 매출은 분리하기 어렵다. |
| 계절 | 2024년과 2025년 봄 주문은 각 비교 기준보다 약 11~12% 많았다. 1월 강세와 12월 약세는 일관되지 않았다. |
| 가격 | 회의록상 2026년 2월 23일이 전 상품 인상 예정일이었다. 먼딜 시작과 상품 변경이 겹쳐 가격만의 효과는 판정하기 어렵다. |

2027년 운영에서는 GA4 구매 추적을 고도몰 주문번호로 대조하고, 광고 세트 예산은 주간 주문 및 신규고객 실적으로 평가한다. 먼딜은 행사 기간과 전후를 포함한 누적 주문·공헌이익을 비교한다. 주문 목록 표시금액에는 최종 환불 정산 차이가 남아 있으며, 이 분석은 관찰 자료의 상관관계를 보여준다.
